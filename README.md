# BE STRONGER — Calorie Calculator V1

Outil web autonome d'estimation des besoins énergétiques pour le sport.

## Utilisation
Ouvrir `index.html` dans un navigateur. Aucun serveur ni compte n'est nécessaire.

## Mise en ligne gratuite
Tu peux publier ce dossier sur GitHub Pages, Netlify ou Vercel.

## Positionnement
L'outil est présenté comme une estimation de bien-être sportif et non comme un bilan diététique ou une prescription nutritionnelle.

## Formule
Mifflin-St Jeor pour le métabolisme basal, puis facteur d'activité. Les objectifs appliquent une variation indicative autour de la maintenance.

## Important
Avant une mise en production commerciale, fais valider les mentions légales, la politique de confidentialité et le positionnement de l'outil par un professionnel compétent en droit français/RGPD.
